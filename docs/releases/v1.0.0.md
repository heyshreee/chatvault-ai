# ChatVault AI v1.0.0

ChatVault AI is a local-first ChatGPT conversation vault. It imports public
`chatgpt.com/share` conversations, stores them in SQLite, exports them as PDF or
DOCX, and answers questions across a local ChromaDB index using Ollama.

## Highlights

- **Import and archive** public ChatGPT share links with URL validation and
  SSRF protections.
- **Export** conversations as styled PDF or editable DOCX, including headings,
  lists, task lists, block quotes, tables, code blocks, and horizontal rules.
- **Search and chat** across indexed conversations with numbered source
  citations. If no indexed context matches, the chat model is not called.
- **Local-first storage** with SQLite as the source of truth and ChromaDB as a
  rebuildable derived index.
- **Six-page React frontend** for the dashboard, AI chat, library, import,
  conversation viewer, and settings.
- **Operational endpoints** for health, statistics, semantic search, index
  status, rebuilds, and model availability.

## Default models

- Chat: `llama3.2:3b`
- Embeddings: `nomic-embed-text`

```bash
ollama pull nomic-embed-text
ollama pull llama3.2:3b
```

## Getting started

```bash
git clone https://github.com/heyshreee/chatvault-ai.git
cd chatvault-ai
make install
make run
```

In a second terminal:

```bash
cd frontend
npm run dev
```

Open <http://127.0.0.1:5173>. Full setup and configuration instructions are in
[README.md](../../README.md).
