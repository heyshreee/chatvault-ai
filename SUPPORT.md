## Questions and bugs

Use [GitHub Issues](https://github.com/heyshreee/chatvault-ai/issues) for:

- Reproducible bugs.
- Feature requests.
- Documentation corrections.
- Setup questions that are not security-sensitive.

Include your operating system, Python version, Node version, the command you
ran, and the relevant error output. Redact conversation text, API keys, and
other private data.

## Security

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).

## Scope

ChatVault AI is a local-first project maintained on a best-effort basis. There is
no hosted service, account system, or guaranteed support response time. Ollama,
ChromaDB, and the selected model are separate dependencies with their own
support channels.
